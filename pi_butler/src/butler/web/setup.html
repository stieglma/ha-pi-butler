    House skills

    Ask in a Pi Web conversation or use /skill:house-explain-automation, /skill:house-why-did-it-happen, /skill:house-why-didnt-it-happen, /skill:house-health-check or /skill:house-memory.

    Inspect installation with /claude:plugin list. After an app update, use /reload in an existing session to discover updated skills.

    What Butler should remember

    Keep device quirks, household preferences and reasons behind your configuration here. Separate confirmed notes from agent observations. These notes are shared by this app’s users.

    Saved privately with the app and retained across restarts and updates. Do not store passwords or tokens.
